מערכת בקשת מסמכים רגולטוריים

שליחה ישירה מ-Gmail שלך — ללא ממוצעים

הגדרה ראשונה — נדרשת פעם אחת בלבד

1

פתח Google Cloud Console ← צור פרויקט חדש ← חפש "Gmail API" והפעל אותו

2

לך ל-APIs & Services → Credentials → Create Credentials → OAuth 2.0 Client ID ← בחר "Web application"

3

ב-Authorized JavaScript Origins הוסף: http://localhost ואת הכתובת שבה תפעיל את הקובץ

4

לך ל-OAuth consent screen ← הוסף את המייל שלך כ-Test user ← שמור

5

הדבק את ה-Client ID שקיבלת:

לא מחובר ל-Gmail
פרטי הנמען
בחר מסמכים נדרשים
יש להתחבר ל-Gmail תחילה
יומן שליחות
